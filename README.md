# Boo's Chocolate Castle Adventure

Полноэкранная браузерная игра для детей 4–6 лет, Peakway Autumn Magic Fest 2026. Три миссии, 15 шоколадных медалек, озвучка, открывающийся сундук, именная по номеру PNG-карточка. Все экраны помещаются в окно без прокрутки.

## Запуск на этом компьютере

Нужен Node.js **24 или новее**. В папке проекта выполните:

```sh
npm run dev
```

Откройте http://127.0.0.1:4173. Окно команды оставьте открытым. После обновлений обновляйте страницу Ctrl+F5. Если сервер был запущен до добавления нумерации, остановите его Ctrl+C и снова выполните npm run dev.

Игра и сервер используют встроенные средства Node.js, установка зависимостей нужна только для тестов.

## Управление

- Три карточки открывают комнату, чердак с привидениями и сад с тыквами. Порядок свободный.
- Кнопка MISSIONS/стрелка возвращает к выбору, сохраняя прогресс.
- Нажимайте предмет, цветное привидение или число, которое называет Boo. После двух ошибок появляется подсказка. Штрафов и таймера нет.
- Тыквы катятся от дальних ворот вниз, исчезают и снова начинают спуск. Пропущенное число возвращается.
- Пять медалек справа в панели задания показывают результат миссии. Общий счётчик — 15 медалек.
- ♪ управляет звуком, ✧ уменьшает анимацию, кнопка рамки включает полноэкранный режим браузера.
- LISTEN AGAIN повторяет инструкцию. После обновления браузер может потребовать этот жест для запуска речи.

## Сундук, номер и сохранение

После 15-й медальки сервер присваивает порядковый номер завершения. Монеты летят к сундуку, крышка открывается, карточка с номером вылетает наружу. SAVE MY CARD скачивает PNG 1254×1254 с вашей иллюстрацией, номером и названием студии.

Номера: B1-000001, B1-000002 и далее, по порядку **завершения**, независимо от порядка входа. Номер сохраняется в SQLite на сервере и в браузере. Повторный запрос не создаёт новую карточку. PLAY AGAIN сохраняет ранее выданный номер. Явная кнопка новой карточки находится в разделе для родителей.

Прогресс хранится в localStorage. Сервер хранит анонимные идентификаторы браузеров и прохождений; имена, телефоны и другие персональные данные не запрашиваются. Входы отражают браузеры, а не достоверное число детей. Подробнее — DEPLOYMENT.md.

Если сервер недоступен, результат сохраняется и предлагается повторить получение номера. Случайный номер вместо порядкового не выдаётся. Данные сервера находятся в data/players.sqlite; не удаляйте базу при обновлении.

## Проверки

```sh
npm install
npm test
npm run build
npm run test:browser
node tests/game-screen.mjs
node tests/pumpkin-browser.mjs
```

Браузерные проверки используют установленный Microsoft Edge и запущенный сервер. Для другого адреса задайте TEST_URL. Отдельная проверка game-screen по умолчанию использует порт 4174 для изолированной тестовой базы. TEST_URL для полного прохождения по умолчанию http://127.0.0.1:4173. Скриншоты и PNG — в test-results/. Не запускайте автоматические прохождения на публичном сервере: они будут учтены как завершения.

Сборка dist/ содержит клиент. Dockerfile добавляет сервер и постоянный том /data. Тестовую базу не включают в релиз. Итоговый отчёт — VALIDATION.md.

## Структура и замена изображений

- src/config.js — задания, пути изображений/MP3, координаты предметов и траектория тыкв.
- src/app.js — игровой процесс и переходы.
- src/screens.js — меню, сундук, карточка и отрисовка PNG.
- src/game-screen.css — полноэкранные сцены и HUD.
- src/state.js — прогресс и монеты, src/pumpkin-race.js — движение тыкв.
- src/registration.js — получение порядкового номера.
- server/counter.mjs — база и общая нумерация, scripts/serve.mjs — HTTP-сервер.
- public/assets/ — ваши PNG и исходные SVG. Описание — ASSETS.md и ASSET-PROCESSING.md.

Предпросмотр: ?preview=home, room, ghosts, pumpkins, complete, final или card. Предпросмотр не создаёт посетителей и номеров, демонстрационная карточка B1-000000.

## Озвучка

Используется системный английский голос Web Speech API; качество зависит от ОС. Для MP3 поместите записи в public/assets/audio и заполните AUDIO в src/config.js. Ключи: welcome; find-pen/rubber/book/chair/pencil; shoot-red/blue/green/yellow/pink; catch-1...catch-10; good; wrong; complete; fifteen; finish; card. При ошибке MP3 используется системная речь. Синтез мягких эффектов — Web Audio.
