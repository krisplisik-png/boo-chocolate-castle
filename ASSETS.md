# Иллюстрации для замены

Текущие сундук, медаль и наградная карточка описаны в **ASSET-PROCESSING.md**. Они заменили SVG-версии этих трёх объектов. PNG-награда теперь квадратная, 1254×1254; исходная карточка не перерисовывается, поверх её свободного поля добавляется серверный номер.

## Подключённые пользовательские изображения

Оригиналы PNG в корне проекта сохранены без изменений. Для публикации используются копии в `public/assets/`:

- `home-map.png` — главная иллюстрация (исходный файл с временем 14_26_42).
- `mission-1.png`, `mission-2.png`, `mission-3.png` — карточки миссий (14_23_24, 14_23_34, 14_23_42).
- `room-art.png` — комната первой миссии (14_14_55-1).
- `attic-art.png` — чердак второй миссии (14_14_57-2).
- `garden-art.png` — сад третьей миссии и декоративный фон страницы (14_15_01-4).

Карточки в главной иллюстрации и отдельные карточки под ней кликабельны. В комнате `POSITIONS` привязан к предметам исходного PNG размером 1672×941. Каждый искомый предмет дополнительно отображается в отдельном SVG-окне с тем же фрагментом исходного фона, имеет собственную кнопку, подсветку и отметку нахождения. При замене комнаты обновите координаты и размеры исходника в функции `game()`.

Коллажи с привидениями, тыквами и школьными предметами сохранены как исходники. Изображение медали подключено ко всем игровым наградам.

Все игровые объекты — самостоятельные изображения и кнопки, не часть единой картинки. Положите PNG в `public/assets/` и переопределите соответствующие значения `ASSETS` в `src/config.js` после объявления объекта, например:

```js
ASSETS.boo = 'public/assets/boo.png';
ASSETS.room = 'public/assets/castle-room.png';
ASSETS.pen = 'public/assets/pen.png';
```

| Ключ | Что предоставить | Рекомендуемый размер |
|---|---|---|
| boo | Доброе белое привидение в фиолетовой шляпе | 600×600, прозрачность |
| castle | Осенний замок для главного экрана | 1600×960 |
| room | Интерьер без пяти искомых предметов | 1600×960 |
| courtyard | Двор без привидений и бластера | 1600×960 |
| garden | Сад с дорожкой без игровых тыкв | 1600×960 |
| pen, rubber, book, chair, pencil | Пять отдельных узнаваемых предметов | 400×400, прозрачность |
| ghost-red, ghost-blue, ghost-green, ghost-yellow, ghost-pink | Пять добрых цветных привидений | 400×400, прозрачность |
| blaster | Волшебный бластер, направленный вверх | 400×400, прозрачность |
| pumpkin | Тыква без числа, число добавляет игра | 400×400, прозрачность |
| coin | Золотая шоколадная медаль с Boo | 400×400, прозрачность |
| chest, chest-open | Сундук закрытый и открытый | 600×600, прозрачность |
| reward-background | Фон карточки без текста и персонажей | 1200×800 |

Персонажи должны иметь одинаковый стиль. Оставьте минимум прозрачных полей вокруг объекта: область нажатия совпадает с его контейнером. Для бластера точка вращения находится внизу по центру. Для сундука сохраняйте одинаковые положение корпуса и масштаб в двух состояниях.

Координаты предметов комнаты находятся в `POSITIONS`: `[left%, top%, width%, height%]`. После замены фона откройте `?preview=room` и скорректируйте проценты. На мобильном экране фон адаптируется по высоте, а предметы сохраняют свои относительные координаты. Убедитесь, что новые изображения не перекрываются и остаются крупными.

Номера на тыквах выводятся отдельно, поэтому достаточно одной иллюстрации без цифры. Карточка рисуется на canvas из того же Boo, медали и фона — замены попадут и в PNG. Используйте локальные файлы: сторонние изображения без CORS могут заблокировать экспорт canvas.
