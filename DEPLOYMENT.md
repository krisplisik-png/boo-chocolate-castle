# Публикация игры с общей нумерацией

Публичная игра доступна по адресу https://boos-chocolate-castle-2026.cozy-coati-7988.chatgpt.site/ . Серверная версия использует Sites Worker и постоянную D1-базу, чтобы все игроки получали номера из общей очереди. D1 API и миграция сохранены в `hosted-worker/`.

## На сервере с Docker

Скопируйте проект и выполните `docker compose up -d --build`. Игра доступна на порту 8080. Настройте HTTPS-домен через обратный прокси хостинга. Том `players` сохраняет базу при перезапуске и обновлении контейнера. Не удаляйте том и регулярно сохраняйте резервную копию `players.sqlite` штатными средствами SQLite. Запускайте один экземпляр приложения, использующий один постоянный диск.

## На хостинге Node.js

Версия Node.js — 24 или новее. Команда сборки: `node scripts/build.mjs`. Команда запуска: `node scripts/serve.mjs`.

Переменные окружения:

| Переменная | Значение |
|---|---|
| HOST | `0.0.0.0` |
| PORT | Порт, предоставленный хостингом |
| SERVE_DIST | `1` |
| COUNTER_DB | Путь на постоянном диске, например `/data/players.sqlite` |

Репозиторий исходников: https://github.com/krisplisik-png/boo-chocolate-castle . Папка `hosted-worker/` содержит маршруты D1 счётчика и схему, развернутые вместе с игрой. GitHub Pages не включён: для общей нумерации нужен серверный API и постоянная база.

## Что считается

- Входы: число анонимных идентификаторов браузеров. Обновление страницы не добавляет вход. Очистка данных или другой браузер создают новый идентификатор. Это приблизительный счётчик устройств/браузеров, не доказанное число детей.
- Завершения: прохождения с 15 разными монетами. Первому новому завершению выдаётся `B1-000001`, второму — `B1-000002` и далее.
- Номер выдаётся по порядку завершения, а не входа. Он не меняется при повторном запросе или обновлении страницы.
- PLAY AGAIN сохраняет уже заработанную карточку. Явный выбор новой карточки создаёт новое прохождение, которое после завершения получает следующий номер.
- Старые случайные номера из предыдущей версии сохраняются как ранее выданные карточки; их нельзя использовать для определения исторической очередности. Серверная последовательность начинается с момента запуска базы.
- Просмотр отдельных сцен через `?preview=...` не создаёт входов и номеров.

Сводка: `GET /api/stats` возвращает `visited` и `completed`; также доступна в разделе для родителей на экране карточки. База и персональные данные не публикуются. Имена и телефоны не запрашиваются. Подтверждение всех 15 монет проверяется сервером, но это игра без регистрации и защиты от намеренной подделки результатов.

При недоступности сервера игра сохраняет 15 монет и предлагает повторить получение номера. Случайный номер вместо порядкового не создаётся.
