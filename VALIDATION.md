# Результаты проверки — 15 октября 2026

Текущая версия: полноэкранная игра без прокрутки, пользовательские медали, анимированный сундук и серверная нумерация наград.

Исправлено направление бластера: расчёт от неподвижного центра вращения SVG, луч выходит из дула и заканчивается в центре выбранного привидения. Во время короткого выстрела цель удерживается на месте, затем продолжает движение/анимацию ответа. `node tests/blaster-browser.mjs` проверяет повторные выстрелы влево/вправо мышью и касанием при 1366×768, 390×844 и 844×390, включая правильные и неправильные попадания. Две дополнительные проверки геометрии входят в `npm test` (всего 10). Скриншоты: `test-results/blaster-aim-*.png`.

- npm test: восемь проверок прошли. Проверены 15 монет, ошибки и повторные нажатия, любой порядок миссий, сохранения, спуск и возврат тыкв, последовательность серверных номеров, повторные запросы и сохранение базы после перезапуска.
- npm run build: клиент собран в dist/.
- npm run test:browser: полное прохождение всех миссий на настольном экране 1440×1000 и эмуляции телефона 390×844. Награда получена с сервера, экспортирована в PNG 1254×1254. Проверены ошибки, подсказки, повторные клики, обновление страницы, сохранение номера, PLAY AGAIN и явный выбор новой карточки. Ошибок JavaScript не зарегистрировано.
- node tests/game-screen.mjs: меню, три миссии, завершение миссии, финальный сундук и карточка проверены при 1366×768, 390×844, 844×390 и 360×640. Прокрутки по обеим осям нет; основные игровые сцены и кнопки находятся внутри окна. Пять индикаторов используют medal-art.png.
- Отдельная проверка HTTP API: незавершённое прохождение отклоняется; восемь одновременных запросов одного результата возвращают один номер; следующий результат получает следующий номер; файл базы не выдаётся через HTTP.
- Ранее node tests/pumpkin-browser.mjs проверил спуск, исчезновение и возврат тыкв, отсутствие потери монет, ловлю мышью и касанием, режим уменьшения анимаций.

Браузерные проверки выполнены на отдельном сервере 4174 с базой test-results/counter-qa.sqlite. Эти номера не относятся к реальным посетителям. Производственная база data/players.sqlite не включает автоматические тесты.

Скриншоты: test-results/fullscreen-*.png. Файл с изображением сундука без фона визуально проверен. Использован встроенный imagegen; prompt и пути — ASSET-PROCESSING.md.

## Ограничения проверки

Мобильные проверки выполнены в эмуляции Edge, не на физических устройствах. Системную английскую озвучку необходимо прослушать на устройстве фестиваля: голос зависит от ОС; автоматические прохождения выполнялись с выключенным звуком. Dockerfile подготовлен, но Docker в этой среде не установлен, поэтому контейнер не запускался. Хостинг и домен не подключены, общая публичная ссылка ещё не опубликована. Готовый сервер необходимо развернуть с постоянным диском согласно DEPLOYMENT.md.
