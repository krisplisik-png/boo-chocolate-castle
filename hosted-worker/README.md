# Публичный сервер игры

Игра: https://boos-chocolate-castle-2026.cozy-coati-7988.chatgpt.site/

GitHub содержит и клиент игры, и исходники D1 API в этой папке. Публичная сборка работает на Sites Worker с D1 привязкой `DB`. Таблицы создаются миграцией `drizzle/0000_nosy_mephisto.sql`; общий порядковый номер выделяется одной SQL вставкой, а повторный запрос для того же запуска возвращает прежнюю карточку.

Файлы игры и изображения берутся из `public/` корневого проекта и копируются в публичный каталог сборки. Для изменения или повторной публикации серверной версии исходники синхронизируются с Sites проектом `Boo’s Chocolate Castle Adventure`; параметры размещения записаны в `.openai/hosting.json`.
